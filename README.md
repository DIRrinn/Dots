# Config's paths

All of them needs to be in home directory

- i3:   `~/.config/i3/config`

- i3lock-color: `~/i3lock-color/lock.sh`

- polybar: `~/.config/polybar/config.ini` and `~/.config/polybar/launch.sh`

- urxvt: `~/.Xresources`

- vim: `~/.vimrc`

# Dependencies
- brightnessctl
- i3lock-color
- urxvt (rxvt-unicode)
- polybar
- rofi
- feh
- vim-plug
